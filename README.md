###  LangGraph Chatbot

A conversational AI chatbot built using **LangGraph, LangChain, Hugging Face, and Streamlit

The chatbot supports conversation history using LangGraph's checkpointing system and provides a simple ChatGPT-like interface through Streamlit.

---

## Features

- Conversational AI chatbot
-  Conversation memory using LangGraph
-  Multiple conversation threads
-  Streaming AI responses
-  Interactive Streamlit interface
- Hugging Face LLM integration


---

## Technologies Used

- **Python**
- **LangGraph** – workflow and conversation state management
- **LangChain** – LLM integration
- **Hugging Face** – language model inference
- **Streamlit** – frontend interface
- **Pydantic / TypedDict** – state management
- **UUID** – unique conversation thread IDs
